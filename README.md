# FinFit — India's Financial Wellness Coach

AI-powered virtual CA + CFA for Indian salaried professionals.

## Deploy on Render

1. Push this repo to GitHub
2. Go to render.com → New → Web Service
3. Connect this repo
4. Settings:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. Deploy → get your URL

## Local Development

```bash
npm install
npm start
# Open http://localhost:3000
```
